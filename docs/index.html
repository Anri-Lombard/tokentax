LLMs charge per token, and the same sentence takes more tokens in some languages than others. Here is how much more, for 222 languages on the tokenizers behind today's models.

How it's measured. Each language's tax is the number of tokens its tokenizer needs for the 1,012 FLORES+ devtest sentences, divided by the tokens the same tokenizer needs for the English versions of those sentences. Every language says the same thing, so the difference is the tokenizer. Lower is fairer.

Text: FLORES+ (OLDI, CC BY-SA 4.0); only counts are published here. Prior work: Petrov et al., Language Model Tokenizers Introduce Unfairness Between Languages (NeurIPS 2023); Ahia et al., Do All Languages Cost the Same? (EMNLP 2023).
